# OpenDeploy rename options

**Leading candidate: Bunait.** No final name has been selected.

Usage checks below were made on **14 September 2026**, unless otherwise noted.
The aim is a distinctive name suggesting foundations, reliability, or deployment.

## Bunait — top option

[Scottish Gaelic for foundation, root, base, or basis](https://www.faclair.com/?txtSearch=bunait).
A direct fit for infrastructure that supports applications.

- **Existing use:** a [Dutch psychology and diagnostic practice](https://www.bunait.nl/).
  No obvious deployment platform using the exact name was found in our searches.
- **Domains:** no registration records found for
  [bunait.com](https://rdap.verisign.com/com/v1/domain/bunait.com),
  [bunait.dev](https://pubapi.registry.google/rdap/domain/bunait.dev), or
  [bunait.io](https://rdap.identitydigital.services/rdap/domain/bunait.io).
- **Developer names:** no exact GitHub account or package on npm, PyPI, or crates.io found.
- **Australian trademarks:** no BUNAIT mark found. The sole search result was
  [FEL, a withdrawn application](https://search.ipaustralia.gov.au/trademarks/search/view/2468101),
  matching an owner's surname, Bunait.

Bunait leads because its meaning fits and its commercial use appears relatively limited.
It does **not** satisfy a strict requirement for zero existing uses.
